Why SSC

왜 Self Security Consulting 인가?

대부분의 조직은 보안이 중요하다는 것을 알면서도 비용과 시간, 전문 인력의 벽에 막혀 있습니다. SSC Platform은 "외부 컨설팅을 사오는 것"이 아니라 "컨설팅 능력 자체를 조직 내부에 두는 것"으로 문제를 풀었습니다.

PROBLEM 01

비싸고 오래 걸린다

전통적인 보안 컨설팅은 연 단위 계약에 수천만 원에서 수억 원이 들고, 착수부터 최종 보고까지 수개월이 걸립니다. 중소·중견기업에게는 사실상 진입이 불가능한 비용 구조입니다.

PROBLEM 02

품질이 사람에 따라 다르다

컨설팅 품질은 투입되는 컨설턴트 개인의 역량에 크게 좌우됩니다. 같은 비용을 내고도 어떤 해는 좋은 보고서를, 어떤 해는 형식적인 보고서를 받게 됩니다.

PROBLEM 03

끝나면 다시 공백이 생긴다

컨설팅은 끝나는 순간부터 낡기 시작합니다. 새로운 취약점(CVE)과 법규 개정에 대응하려면 매년 재계약해야 하고, 그 사이 기간은 보안 공백으로 남습니다.

PROBLEM 04

내부 데이터를 외부에 보여줘야 한다

컨설팅을 받으려면 자산 목록, 네트워크 구성, 취약점 정보 같은 가장 민감한 데이터를 외부 인력에게 공개해야 합니다. 이것 자체가 또 하나의 보안 리스크입니다.

수일이 걸리는 컨설팅 과정 전체를 언제든 저장하고 다시 불러올 수 있습니다. 서버가 재시작돼도 자동으로 상태가 복원되고, 5분마다 자동 저장됩니다. 바쁜 IT팀의 현실적인 업무 흐름에 맞춘 설계입니다.

ISO 27001 Consulting

보안 컨설팅 6단계 워크플로우

실제 보안 컨설팅 회사가 수행하는 절차를 ISO 27001:2022 기준으로 6단계로 표준화했습니다. 각 단계는 AI 에이전트가 수행하고, 단계가 끝날 때마다 담당자의 승인을 받아야 다음으로 진행됩니다.

1PHASE

사전 준비 · 킥오프

컨설팅 범위와 목표를 정의하고 프로젝트를 시작합니다. PM 에이전트가 조직 규모·산업·고객 유형에 맞는 제안서를 자동 작성하고, NDA와 킥오프 회의 안건까지 준비합니다.

제안서 자동 생성범위 정의킥오프
2PHASE

현황 분석 · 갭(Gap) 분석

관리적·기술적·물리적·컴플라이언스 4개 영역의 현재 보안 수준을 분석합니다. IT 자산을 식별해 기밀성·무결성·가용성(CIA) 등급을 매기고, ISO 27001의 93개 통제항목 각각에 대해 현재 수준(0~5)과 목표 수준의 차이(갭)를 정량화합니다.

93개 통제항목 갭 분석자산 식별 · CIA 등급4개 영역 현황
3PHASE

위험 평가 · 위험 등록부

발견된 갭을 "얼마나 일어나기 쉽고, 일어나면 얼마나 아픈가"의 5×5 매트릭스로 평가합니다. 위험도는 가능성×영향도로 자동 계산되며, 각 위험에 대해 수용·감소·전가·회피 중 처리 전략을 수립해 위험 등록부로 관리합니다.

5×5 위험 매트릭스위험 등록부처리 전략 4종
4PHASE

보안 대책 설계 · 정책 체계

위험을 줄이기 위한 관리적·기술적·물리적 보안 대책을 설계하고, 전사 정책 → 보안 정책 → 업무 절차 → 작업 지침의 4계층 정책 체계를 수립합니다. 대책별로 긴급(1주)·단기(1개월)·중기(6개월)·장기(1년) 이행 로드맵이 만들어집니다.

4계층 정책 체계이행 로드맵예산 · 난이도 평가
5PHASE

이행 지원 · 검증

정책 구축과 직원 교육을 지원하면서, 인프라·웹·모바일·모의침투·소스코드 5개 도메인에 대한 취약점 진단을 실제로 수행합니다. 진단이 끝나면 Pre-Audit(사전 감사)로 관리·기술·물리·운영·인식 5개 영역을 검증합니다.

5개 도메인 취약점 진단CVSS v4.0 평가Pre-Audit
6PHASE

최종 보고 · 사후관리

9개 챕터의 최종 보고서와 경영진 요약 보고서가 DOCX/PDF로 자동 생성됩니다. 컨설팅 종료 후에도 하자보수, 분기별 정기점검, 신규 위협 긴급대응, ISO 27001 인증 유지 체계가 계속 동작합니다.

Red Team

PTES 8단계 모의해킹 워크플로우

문서 점검만으로는 실제 공격을 막을 수 있는지 알 수 없습니다. 8종의 Red Team 에이전트가 국제 모의해킹 표준 PTES(Penetration Testing Execution Standard)에 따라 실제 공격자의 절차를 그대로 수행합니다. 모든 공격 행위는 사전 승인(ROE) 범위 안에서만 실행됩니다.

1·2PTES

사전협의 → 정보수집

공격 범위와 교전 규칙(ROE)을 문서로 합의한 뒤, 공개 정보(OSINT)·DNS·인증서를 수집해 외부에서 보이는 공격 표면(Attack Surface)을 매핑합니다. "공격자의 눈에 우리 회사가 어떻게 보이는가"를 먼저 확인하는 단계입니다.

3·4PTES

위협 모델링 → 취약점 분석

MITRE ATT&CK에서 우리 조직에 유효한 공격 기법(TTP)을 선정해 공격 시나리오를 설계하고, 웹·인프라·클라우드·모바일·AI/LLM 5개 영역의 전문 에이전트가 병렬로 취약점을 스캔합니다. 발견된 취약점마다 CVSS v4.0 점수가 매겨집니다.

5·6PTES

익스플로잇 → 후속 공격

발견된 취약점이 실제로 뚫리는지 PoC(개념 증명)로 검증하고, 침투에 성공하면 어디까지 피해가 번지는지(Blast Radius) 횡적 이동과 데이터 접근 가능성을 측정합니다. 위험한 행위는 모두 승인 게이트를 거칩니다.

7·8PTES

보고 → 재검증

기술 보고서와 경영진 보고서를 자동 생성하고, 조치가 완료되면 같은 시나리오로 재검증해 취약점이 정말 제거되었는지 확인합니다. "발견"이 아니라 "제거 확인"까지가 모의해킹의 완성입니다.

Real Scanning

시뮬레이션이 아닌 실측 스캐닝

LLM이 "아마 취약할 것"이라고 추측하는 것이 아니라, 실제 스캐닝 도구를 호출해 측정한 결과로 판단합니다. 동시에, 스캐닝 자체가 사고가 되지 않도록 안전장치를 코드 레벨에서 강제합니다.

⌖

4종 실측 스캐너

Nmap 포트 스캔(열린 포트·서비스 버전), SSL/TLS 검사(인증서 유효성·취약 프로토콜·약한 암호), DNS 열거(서브도메인 탐색), HTTP 보안 헤더 검사(HSTS·CSP 등 6종)를 비동기로 실행합니다.

⛨

화이트리스트 + 승인 토큰

스캔 대상은 사설망 주소와 사전 허용된 도메인으로 제한되며, 실행에는 승인 토큰이 필요합니다. 실수로 외부 시스템을 스캔해 법적 문제가 생기는 일을 구조적으로 차단합니다.

Governance

AI를 신뢰하게 만드는 승인 게이트 · 거버넌스

"AI가 알아서 했습니다"는 보안 컨설팅에서 허용되지 않는 문장입니다. SSC Platform의 모든 중요 결정에는 사람의 승인과 기록이 남습니다.

✋

고객 유형별 다중 승인

정부기관 3인 → 금융권 2인 → 일반기업 1인. 조직의 민감도에 비례해 승인 인원이 늘어납니다. 48시간 내 응답이 없으면 자동 에스컬레이션되고, 반려 시에는 사유 분류와 재수행 가이드가 제공됩니다.

⚿

인증 · 역할 기반 접근 제어

JWT 인증에 사내 LDAP/Active Directory 연동을 지원하며, ADMIN·AUDITOR·VIEWER 3단계 역할로 누가 무엇을 볼 수 있는지 분리합니다.

≡

전 과정 감사 추적

모든 에이전트 호출, 승인·반려, 데이터 변경이 감사 로그로 기록됩니다. "그때 왜 그렇게 판단했는가"를 언제든 재구성할 수 있어 ISMS·ISO 심사 대응 자료로 그대로 활용됩니다.

Harness Engineering

에이전트를 지탱하는 5계층 하니스

AI 에이전트를 "잘 돌아가게" 하는 것과 "믿고 맡길 수 있게" 하는 것은 다른 문제입니다. SSC Platform은 5개 계층의 하니스(통제 구조)로 에이전트의 안전·관측·복원·품질·진화를 보장합니다.

L1Safety — 안전

승인 게이트, 에이전트 샌드박스(토큰·요청 제한), 개인정보(PII) 마스킹, 악성코드 패턴 차단.

L2Observability — 관측

모든 에이전트 호출의 입출력·토큰·시간 추적, 단계별 소요시간·실패율 메트릭, LLM 헬스 대시보드.

L3Resilience — 복원

Circuit Breaker(연속 실패 시 자동 차단), 자동 저장, 서버 재시작 시 상태 복원, 점진적 성능 저하(Graceful Degradation).

L4Quality — 품질

에이전트 출력 100점 척도 검증, 보고서 챕터·표·CVSS 유효성 검사, 회귀 테스트 30건.

L5Evolution — 진화

지식베이스 자동 업데이트, 모델 교체 시 Shadow → A/B → Canary → 전체 적용의 단계적 마이그레이션.

Vision

기대 효과와 비전

보안 컨설팅의 진입 장벽이 사라지면, 그동안 보안 투자를 미뤄왔던 수많은 조직이 스스로를 진단하고 개선할 수 있게 됩니다. 이것이 국가 전체의 사이버 보안 수준을 끌어올리는 길이라고 믿습니다.
